My projects

BSc final project · Healthcare

1.1 MyMOB

Stages
10
Roles
3
Hospital
1

A clinical platform that tracks the mobility of elderly surgical patients, built in partnership with Hospital Dr. José Maria Grande in Portalegre.

Each patient follows a ten-stage clinical process, from medical triage to discharge: frailty (CFS), sarcopenia (SARC-F) and physical performance (SPPB) screening, an exercise plan, and daily session records with safety parameters. Surgeons, physiatrists and physiotherapists each see their own part of it, and triage and referral decisions are Drools rules behind a REST API with role-based access.

My role: I built the whole platform as my final project for the BSc in Computer Engineering.

  • Java
  • Spring Boot
  • Drools
  • MySQL
  • JWT
  • React
  • TypeScript

Control and monitoring of a hydrogen production reactor: calibration, operating modes, membrane hydration, voltage ramp, cooling and H₂ production with cyclic purging.

1.4 Tangible Interface for VR

An international week at Haute École Louvain en Hainaut (HELHa) with students, teachers and researchers from across Europe. The challenge was to design and build tangible interfaces for VR: devices with motion sensors (IMUs) that capture real-world movement and send it to a VR headset.

My role: working in a group through workshops and classes, I wrote the Arduino code for a board with an IMU (accelerometer and gyroscope) that moves the maze board built in Godot, which is seen in virtual reality.

  • Arduino
  • ROS 2
  • Godot Engine

1.5 Lead CRM

A CRM for sales leads, built as a technical challenge: create, edit and delete leads, search by name or email, filter by status, and a sidebar with totals per status and the latest leads.

My role: The code is split into layers, like a controller and a service in Spring Boot: routes only handle HTTP, the service holds the rules, and one function maps errors to status codes. Pagination runs on the server.
